# Contributing

Thanks for helping improve this roadmap. The goal is simple, practical advice that a working DevOps or platform engineer can trust.

## Ways to help

- Add a tool, resource, or short guide under the right section.
- Fix something that is out of date or wrong.
- Improve the wording so it is clearer and easier to read.
- Share a real pattern you use, with a note on where a human stays in control.

## A few guidelines

- Keep it practical. Real, tested advice is worth more than hype.
- When you add a tool, say what it does in one plain sentence.
- Tag anything that takes action with a trust level: Assist, Gate, or Auto. Add one line on where the human or a policy check stays in the loop.
- Prefer open-source and widely used tools. If you add something niche, say why it is worth knowing.
- Write in plain language. Short sentences are good.

## How to submit

1. Fork the repo and create a branch.
2. Make your change.
3. Open a pull request with a short description of what you changed and why.

That is it. Thanks again.
